NFL Fullstack App — React + Laravel
Application fullstack dédiée à la NFL, réalisée par passion et dans un objectif d'apprentissage approfondi du développement web.
Navigation entre conférences, divisions et équipes avec tableaux dynamiques, tris et filtres, carte interactive des franchises, et espace utilisateur sécurisé.
Stack

Frontend : React, Redux Toolkit, React Router, Ant Design, Tailwind CSS
Backend : Laravel, Laravel Sanctum
Base de données : MySQL
HTTP : Axios

Fonctionnalités

Authentification sécurisée (inscription, connexion, tokens Sanctum)
Gestion des rôles admin/user avec contrôle d'accès backend
CRUD joueurs et équipes avec validation et relations MySQL
Carte interactive des franchises NFL
Gestion d'état global avec Redux (filtrage dynamique)
Interface responsive avec composants réutilisables
